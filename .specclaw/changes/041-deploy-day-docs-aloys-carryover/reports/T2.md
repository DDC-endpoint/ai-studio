**Defect found and fixed in the doc.**

- All 7 public URLs (kit logos, artifacts, generated backgrounds, brief image) answered **403**.
- Cause: `initBuckets()` sets the public-read policy only from `uploadObject`, so it happens on the first upload, not at startup.
- Fixes:
  - Step 6 gained `mc anonymous set download` for `generated-images` and `brand-kits`. After it, all 7 URLs return 200 with `image/png` or `image/jpeg`, and an anonymous read of `exported-designs` still returns 403.
  - §3's "creates them on startup" claim is corrected.
  - `mc alias rm src` and `mc alias rm dst` were added, so the MinIO keys don't stay in a container's `mc` config.
- T1's `DO $ … $` quoting defect was fixed before the rehearsal. The rehearsal ran the corrected block.
