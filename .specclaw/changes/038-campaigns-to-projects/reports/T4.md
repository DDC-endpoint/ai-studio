# T4 report — assign and apply routes with their events; post page Project block; library filter and card control; dashboard

Implementer: general-purpose (sonnet).

## Summary

- `PUT /api/drafts/[id]/project` (view tier): writes `Brief.projectId` in a transaction that locks the live target project (`FOR SHARE`, `isDeleted = false`); foreign/deleted/unknown → 404 PROJECT_NOT_FOUND; emits `draft.project_changed` (`change`, `fromProjectId`, `toProjectId`); a no-op emits nothing.
- `POST /api/drafts/[id]/apply-project` (edit tier): compare-and-set on `generationInputs` with `pendingAction` null and status not IN_PROGRESS; 409 `busy` / `no-change` / `changed`; recomputes the facts check; emits `draft.inputs_applied` (`fromProjectId`, `toProjectId`, `kitChanged`, `briefingChanged`, `factsStatus`).
- Project DELETE now soft-deletes before unassigning, so a concurrent assign cannot land on a deleted project.
- Draft GET adds `project` and `inputsCurrent` (computed only for EXPORTED and idle drafts).
- Library route: per-item `project` and `canEdit`; kit filter on the stamp's `kitId` with brief-kit fallback. Library page: Project filter; `LibraryCard` shows the project, a `ProjectPicker`, and Delete only when `canEdit` (T1 carry-over).
- Post page: Project block with `ProjectPicker` and "Apply project settings" (edit tier, only when not current).
- Dashboard: "Projects" KPI; recent drafts column "Project".
- Unit: new assignProjectRoute, applyProjectRoute; updated libraryRoute, libraryHeadlineState, draftDetailGet, analyticsCoverage, projectDelete.
- E2E: projects TC-PROJ-10..12 + assign 404, post-permissions TC-PERM-07, library TC-LIB-07/08, ui TC-UI-08 + KPI, team-isolation assign cross-team, a11y.
